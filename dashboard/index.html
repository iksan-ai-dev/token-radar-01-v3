TOKEN RADAR v3

Every protocol that records no token, ranked by what its token would be worth if the record stayed as it is. Not a prediction of whether or when a token launches.

HOW A ROW IS VALUED

No name is special-cased. Every number above is fitted at runtime from the snapshot itself: the curve from the 128 protocols that record a token, the category effect shrunk with 4 pseudo-comparables, the age and growth factors from each protocol's own listed date and 7-day change. A protocol's implied value is this entry's model, not a claim by the data source.

MODEL & LIMITS — READ THIS BEFORE YOU FARM

What the model uses

  • TVL — the protocol's total value locked, from the snapshot.
  • Size curve — bigger protocols trade at lower mcap/TVL; the curve is fitted, not assumed.
  • Category effect — shrunk toward zero, so one odd comparable cannot set a whole category.
  • Age without a token — longer un-tokenised runs score higher, up to 730 days.
  • 7-day growth — rising TVL lifts the value, falling TVL cuts it, both clamped.
  • Kin discount ×0.5 — a sibling protocol (same family word, smaller value) is worth half its curve value: one family, one launch.
  • Farm verdict — a triage on launch size: top 10 by implied value are worth a ticket, ranks 11–50 are thin, the rest too small for a standard ticket. The slice-per-$1K column shows the dilution on the biggest launches alongside it.

What the model gets wrong

  • It has no fees, revenue, users or funding data — the snapshot carries none — so a loud protocol and a quiet one with the same TVL score the same.
  • Market cap here is circulating mcap, not fully diluted value; a launch's FDV is usually higher.
  • “Records no token” is a record, not proof: a protocol on this board may already have a token its record misses.
  • Curators and capital allocators (Risk Curators, Onchain Capital Allocator) are vault managers, not standalone protocols; their launch is the least certain shape on this board, and the P25–P75 range says so.
  • The range is wide on purpose — the median comparable is mis-priced ×3.40 by the curve. Treat every point value as the middle of a wide range.
